# 安装与使用

本包是普通的文件式 Skill，入口为 `SKILL.md`，不是需要某个产品模板库的专用产物。使用UTF-8文本、相对资源路径，不需要API密钥、付费服务或安装脚本。

## 安装

1. 解压ZIP，得到完整的 `acca-hr-minutes/` 目录。
2. 将整个目录放入目标Agent支持的skills目录，或通过其本地Skill导入功能选择该目录。具体目录与导入操作以目标工具要求为准。
3. 保留 `references/` 和 `assets/`。只复制入口文字无法复现表格及文书标准。
4. 如目标Agent不会自动发现新Skill，按其要求刷新或重启会话，再明确要求使用 `acca-hr-minutes`。

不支持SKILL.md的Agent，可把SKILL.md作为任务/系统参考指令，并提供references文件、Word模板和文书标准PDF。它不会因此自动获得录音转写、Word编辑或PDF渲染能力；这些能力需由宿主工具提供。

示例调用：

```text
请使用 acca-hr-minutes 整理本次HR例会。
会议日期：实际日期；时间：实际开始时间；地点：实际地点。
出勤：实际出席/请假情况。
附件：本次录音、PPT或会议笔记。
请同时给出会议纪要、随信通知、Word编辑稿和PDF分发稿。
```

默认部门HR、整理人和通知署名李嘉辰、缩写LJC、例会通知群“HR耍起俱乐部”。可以在请求中明确覆盖。新Agent没有本会话历史，仍需提供本次会议材料、日期、次数等事实。

## 资源来源与边界

- `assets/meeting-record-template.docx`：用户提供的原始会议记录模板，未改动。
- `assets/document-standard.pdf`：用户提供的原始ACCA Club文书标准，未改动。
- `assets/template-preview.png`：原始模板第一页的渲染图，只用于识别结构。标题排版差异按references中的规则解决。
- 指令根据本会话已确认的规则与用户纠正提炼。包中不包含历史会议录音、转写文本、PPT账号密码或本地转写模型。

本包供用户及其获授权的Agent使用，未对社团原始模板的第三方再分发权作额外声明。安装包不自动修改目标Agent的全局设置，也不发送通知或启用任何后台任务。
